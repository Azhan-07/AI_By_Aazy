# 🤖 AI_By_Aazy

**A custom AI model packaged and published using Ollama.**

AI_By_Aazy is my personal AI project, created by customizing and publishing a local language model through Ollama. My goal is to explore local AI, model customization, and making AI models accessible to other developers.

## 🚀 Get Started

### Prerequisites

* [Ollama](https://ollama.com/download) installed on your computer.
* An internet connection for the initial model download.

### Installation and Usage

Run the following command in your terminal:

```bash
ollama run aazhan98/ai-by-aazy
```

Ollama will download the model if necessary and start an interactive chat.

To download the model without starting a chat:

```bash
ollama pull aazhan98/ai-by-aazy
```

## ✨ Project Goals

* Explore local large language models (LLMs).
* Learn model customization using Ollama.
* Make a customized AI model available to other users.
* Explore privacy-conscious, locally run AI applications.

## 🛠️ Technology Stack

* **Ollama** — Local model execution and distribution.
* **LLM** — Based on the Qwen 2.5 3B model, as used in my local setup.
* **Modelfile** — Model configuration and customization.
